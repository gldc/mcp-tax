# MCP Tax implementation plan

> For agentic workers: use subagent-driven-development for bounded implementation, with parent verification.

**Goal:** Publish a source-backed MCP pricing directory at mcp-tax.com from public gldc/mcp-tax.

**Architecture:** Static HTML generated from structured vendor JSON, enhanced with browser JS. No runtime service or credentials. GitHub Actions builds and deploys GitHub Pages.

**Tech stack:** Node 24, HTML, CSS, browser JavaScript, JSON, GitHub Actions.

## Global constraints

- Work only in the isolated feat/launch worktree.
- Follow the approved design in ../specs/2026-11-10-mcp-tax-design.md.
- Official vendor sources, checked 2026-11-10, no invented prices or inferred free access.
- Keep future charges and previews explicit; distinguish product costs from MCP costs.
- No direct push to main; source goes through a PR.

### A. Evidence dataset

Files: data/vendors.json, docs/research.md, scripts/validate.mjs, tests/data.test.mjs.
